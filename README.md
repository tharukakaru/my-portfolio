# Midnight Core Portfolio

A modern personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.  
This site presents my background, experience, projects, skills, education, and contact information in a clean, premium interface.

## Author

Built and maintained by Tharuka Karunarathne

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Features

- Responsive single-page portfolio
- Smooth animations and modern UI
- Dedicated sections for about, experience, projects, skills, education, and contact
- Built for fast deployment on Vercel
